# 需求澄清清单（前端补充）

> 面向当前若依 Vue 3 前端；通用问题先看 `spec/guides/requirement-clarification.md`，这里补充当前仓库最容易遗漏的前端落地问题。

## 1. 页面与入口

- [ ] 页面入口来自后端菜单、静态路由，还是隐藏详情页？
- [ ] 页面文件准备放在哪个 `src/views/**` 目录下？
- [ ] 是否需要新增详情页、授权页、导入页等隐藏路由？

## 2. 权限与菜单

- [ ] 按钮权限字符串是什么？是否已经有对应后端权限？
- [ ] 是否需要新增菜单、按钮、目录或面包屑高亮配置？
- [ ] 后端菜单 `component` 字段应该映射到哪个页面路径？

## 3. 页面结构与交互

- [ ] 页面是标准“查询 + 表格 + 弹窗”模式，还是树表 / 分步页 / 主子表模式？
- [ ] 是否需要 `RightToolbar`、`Pagination`、导入导出、状态开关？
- [ ] 是否有字典字段、上传下载、富文本或图片预览？
- [ ] 按钮、菜单、表格操作的触发条件 / 可见条件 / 禁用条件是否明确？
- [ ] 弹窗 / 抽屉 / 详情页的打开、关闭、返回路径、二次确认规则是否明确？
- [ ] 空态、加载态、异常态、无权限态分别如何展示？
- [ ] 字段联动规则是否明确：某字段变化后，哪些字段需要显示 / 隐藏 / 禁用 / 必填切换 / 清空 / 自动带出？
- [ ] PRD 与原型在“跳页 / 弹窗 / 抽屉 / 行内编辑”上的表现是否一致？

## 4. 数据与接口

- [ ] 接口路径和返回结构是否已明确？
- [ ] 需要新增哪些 `src/api/**` 与 `src/types/api/**` 文件或方法？
- [ ] 查询参数是否包含分页、时间范围、状态、部门树等特殊结构？
- [ ] 下拉、单选、级联等选项来源是什么：固定枚举、`useDict`、接口还是配置？
- [ ] 默认值由谁提供：前端初始化、后端回填、路由参数、缓存条件还是草稿数据？
- [ ] 展示字段分别来自哪个接口 / 字段？提交后分别写入哪个接口 / 实体？
- [ ] 联动字段切换后，是否需要重新拉取下游选项、清空旧值、重跑校验或改写提交参数？
- [ ] 是否需要回显和恢复查询条件、路由参数、分页状态？

## 5. 状态管理

- [ ] 是页面局部状态还是跨页面共享状态？
- [ ] 是否真的需要 Pinia，还是页面内部 `ref/reactive` 即可？

## 6. 验收方式

- [ ] 主要手工验证路径是什么？
- [ ] 是否需要构建验证或额外类型检查？
- [ ] 权限分支、空状态、异常提示需要如何验收？

## 7. 严格差异扫描输出契约（PRD / 原型 / 现有页面）

当输入同时包含 `PRD`、原型、截图、现有页面说明、前端页面路径（如 `src/views/**`）或明显 UI 交互需求时，`brainstorming` 不得只给模块级摘要，必须进入页面级严格扫描模式。

### 7.1 必须先给出页面覆盖范围

- [ ] 先输出 `受影响页面清单`，列出已核对的页面、弹窗、抽屉、详情页、跳转流程
- [ ] 若某个受影响页面尚未核对，必须标记为 `未核对`，并计入 blocker
- [ ] 不允许在未列出页面覆盖范围时直接下“字段完整 / 无明显差异”结论

### 7.2 每个页面必须核对的检查项（检查项 ≠ 输出表头）

为避免和 `prd-diff-scan` 的输出契约混淆，这里的检查项统一拆成 3 个输出区域：

- [ ] **字段对比表**（不计入 9 维度）：查询条件 / 筛选项 / 默认筛选值；表格列 / 卡片字段 / 详情区字段；表单字段 / 必填规则 / 校验规则；行操作 / 按钮 / 菜单
- [ ] **9 维度交互/联动表**：交互行为；触发事件；数据来源；数据流向 / 提交落点；字段联动；状态流转；权限与角色；默认值 / 默认排序 / 默认分页 / 回显规则；字典 / 下拉 / 级联选项来源
- [ ] **页面级验收点**（不计入 9 维度）：正向、空态、异常态、权限态
- [ ] **未核对项** 必须回填到页面级 blocker，不能因为写进了别的表就默认算已核对

### 7.3 默认 blocker 规则

以下项只要还未核对或存在冲突，默认就是 blocker：

- [ ] 交互行为
- [ ] 触发条件
- [ ] 字段联动
- [ ] 数据来源
- [ ] 数据流向 / 提交落点
- [ ] 默认值 / 默认排序
- [ ] 权限归属
- [ ] 字典 / 下拉来源

只有纯视觉样式或不影响实现判断的文案差异，才默认不是 blocker。

### 7.4 推荐输出格式

```md
## 受影响页面清单
| 页面/流程 | 当前实现/原型依据 | 核对状态 | 备注 |

## 页面级字段对比
| 页面/流程 | 区域 | PRD/原型字段 | 当前实现字段 | 结论 | 是否已核对 |

## 页面级交互/联动对比
| 页面/流程 | 维度 | PRD/原型 | 当前实现 | 结论 | 是否阻塞 |

## 页面级验收点
| 页面/流程 | 验收场景 | 预期 | 当前实现依据 | 结论 |

## 未核对项
- 页面：...
  - 未核对维度：字段对比 / 9维度交互表 / 验收点

## Blockers
- ...

## 差异决议
- ...
```
